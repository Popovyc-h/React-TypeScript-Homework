# Домашнє завдання: Основи TypeScript

> Практичні базові завдання для першого знайомства з TypeScript.  
> Виконуйте завдання послідовно в окремому файлі (наприклад, `homework.ts`).

---

### Завдання 1: Базові примітивні типи

- Створи змінні з явно вказаними типами:
    - `userName` — рядок (`string`);
    - `userAge` — число (`number`);
    - `isAdmin` — булеве значення (`boolean`).
- Створи масив рядків `skills`, який містить декілька технологій (наприклад: `['HTML', 'CSS', 'JS']`).
- Спробуй присвоїти змінній `userAge` рядкове значення та переконайся, що компилятор TypeScript підсвічує помилку.

---

### Завдання 2: Типізація функцій

- **Форматування ціни:** Напиши функцію `formatPrice(price: number, currency: string): string`, яка повертає рядок у форматі `"$100"` або `"100 грн"`.
- **Привітання з необов'язковим параметром:** Напиши функцію `greet(name: string, title?: string): string`.
    - Якщо передано `title` — повертає `"Hello, Mr. John"`.
    - Якщо не передано — повертає `"Hello, John"`.
- **Порожня дія:** Створи функцію `logMessage(message: string): void`, яка лише виводить повідомлення в `console.log`.

---

### Завдання 3: Інтерфейси (Interfaces) та Об'єкти

- Створи інтерфейс `User` з полями:
    - `id` — тільки для читання (`readonly number`);
    - `name` — рядок (`string`);
    - `email` — рядок (`string`);
    - `phone` — необов'язковий рядок (`string?`).
- Створи змінну `user1` типу `User` та заповни її даними.
- Спробуй перезаписати `user1.id = 999` і перевір реакцію TypeScript.

---

### Завдання 4: Type Aliases та Union Types

- Створи тип `ID`, який може бути або `string`, або `number`.
- Створи аліас типу `OrderStatus`, значеннями якого можуть бути тільки строкові літерали:
    - `'pending' | 'shipped' | 'delivered' | 'cancelled'`
- Напиши функцію `printStatus(orderId: ID, status: OrderStatus): void`, яка виводить id замовлення та його статус.

---

### Завдання 5: Перерахування (Enums)

- Створи `enum Role` зі значеннями: `Admin`, `User`, `Guest`.
- Напиши функцію `checkAccess(role: Role): boolean`:
    - Повертає `true`, якщо передано `Role.Admin`.
    - Повертає `false` для всіх інших ролей.
- Протестуй виклик функції з різними ролями.

---

### Завдання 6: Звуження типів (Type Narrowing)

- Напиши функцію `doubleValue(input: string | number): string | number`.
- Використай оператор `typeof` всередині функції:
    - Якщо `input` — число, повертай його подвоєне значення (`input * 2`).
    - Якщо `input` — рядок, повертай рядок, повторений двічі (`input + input` або `input.repeat(2)`).

---

### Завдання 7: Класи та модифікатори доступу

- Створи клас `BankAccount`:
    - `public owner: string` — ім'я власника рахунку;
    - `private balance: number` — баланс (початково дорівнює переданому значенню або `0`);
    - `constructor(owner: string, balance?: number)`.
- Додай методи:
    - `deposit(amount: number): void` — поповнює баланс, якщо сума більша за `0`;
    - `getBalance(): number` — повертає поточний баланс.
- Створи екземпляр класу та перевір:
    - Поповнення рахунку та перевірку балансу через `getBalance()`;
    - Спробуй напряму звернутися до `account.balance` поза класом і переконайся, що TypeScript видає помилку доступу.
